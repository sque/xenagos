# Mockups

Static screens drawn while specifying this change. They show layout only; nothing is interactive.

| File | What it shows |
|---|---|
| `b-walkthrough-chosen.html` | Walkthrough mode as approved (design decision 5b): explorer, header, visual, whole-file code with spotlight and caption, selection question, outline, agent terminal. |
| `b-explorer-all-files.html` | The approved layout with "All" selected in the explorer: every file listed, unchanged ones muted, change marks kept. |
| `narration-menu.html` | The menu behind the speaker icon: voice settings and wording settings. |
| `browse-mode.html` | Browse mode before any agent session exists. |
| `c-narrator-colour-not-chosen.html` | The approved layout with one colour and mark for everything the narrator owns (current file, current step, sketch, caption). Considered and not chosen: too much. |
| `a-walkthrough-not-chosen.html` | The first walkthrough layout, kept for comparison. Not the design. |

Open the `.html` files in a browser; they are 1440 by 900. `.png` files are captures of the same screens.
`source/` holds the files as authored on the design canvas; they need that canvas to render.
